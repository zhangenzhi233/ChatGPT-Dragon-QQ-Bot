# 龙娘素材使用说明

本目录包括两张普通版/Q 版角色参考图、29 张银白龙 PNG 表情、预览和描述清单。项目维护者已确认有权把这些素材随本项目公开，并供其他使用者制作自己的本地聊天机器人。

这些图片独立于源码 GPL/MIT 许可；当前说明不授予额外的商业使用权、转售权或独立素材包再许可权。希望进行这些用途时，请先向项目维护者确认原素材授权范围及署名要求。

部分表情由 AI 参考角色图生成或高清重绘。原参考图创作者署名应由维护者在获得完整来源信息后补充；此处不臆造作者。

`stickers/*/manifest.json` 保存文件名、哈希、情绪标签与可见内容描述，用于导入校验和角色匹配。不包含原机器文件路径、账号或生成调试记录。
