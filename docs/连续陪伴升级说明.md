# 连续陪伴更新（2026-10-15）

本轮改善现有 MaiBot 主动聊天：待跟进事项、有来源的话题、发送结果关联。没有迁移框架。

## 能感受到的变化

1. 你明确提过但还没处理完的事情，可以在后续评估中被自然接着聊。明确说完成或取消后，事项可以关闭；时间到了只会过期，不能当成完成。
2. 主动联系优先围绕聊过的事情、新进展、动态或新闻。同一来源72小时内不重复尝试；少量自然问候每24小时最多一次。未获新反馈的事项不反复追问。
3. 入队与发送结果分别记录。部分发送、回执不明均不会被记成完整送达，也不会自动补发已发送内容。新消息到来时，尚未发送的主动回复可以让位。

## 使用与边界

- 沿用已有主动聊天开关、每天次数、最短间隔和静默时段。此次没有修改账号、模型、人设、声音、空间权限或这些配置。
- 跟进仍由模型判断，程序校验消息来源、原文、时间和状态。它可能漏记或误判语义，需要自然使用观察；不提供准点提醒保证。
- 待处理事项最多8条；默认约四小时后适合跟进、三天过期，程序限制最长七天。角色虚构经历不会因此获得用户事实或公开动态来源的资格。
- 复用现有调度模型的一次请求，输出上限512→1200 tokens，请求次数不增加，实际输出额度可能增加。
- 事项及原文片段保存在本机插件状态，并通过原有模型通道参与评估；没有新接第三方服务。宿主回执只保存编号、分段状态和时间，不保存正文。
- “发送成功”表示宿主发送链取得成功结果；QQ手机显示、语音播放和用户已读仍须分别确认。
