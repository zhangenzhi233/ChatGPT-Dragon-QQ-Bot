# 银白龙按需语音

此插件只在当前 QQ 私聊的请求者已被授权时工作。它使用 Edge TTS 合成 MP3，并通过现有 NapCat 适配器发送为 QQ 语音（`record`），不发送文件附件。

源码随 ChatGPT-Dragon-QQ-Bot 发布；`_manifest.json` 的仓库链接指向本项目。更新前请保留自己的本机配置。

## 配置

默认关闭。完成根目录 README 的账号设置后，可运行 `scripts/configure-features.py --voice on` 生成仅授权自己主号的本机配置，再在插件管理中加载或重载。也可从 `config.example.toml` 手动建立 `config.toml`：

- `voice.voice`：音色，默认 `zh-CN-XiaoxiaoNeural`；
- `voice.rate`：语速，默认 `-6%`；
- `voice.pitch`：音高，默认 `+8Hz`；
- `voice.timeout_seconds`：一次合成的超时秒数；
- `voice.max_length`：一次最多朗读的字符数；
- `voice.greeting_text`：`/试听` 朗读的固定测试文本；
- `access.allowed_user_ids`：允许使用的 QQ 号。空列表会拒绝全部请求。

主程序环境需要安装 `edge-tts==7.2.8`。本插件依赖已启用并可发送 QQ 语音的 `maibot-team.napcat-adapter`。

## 使用

授权 QQ 私聊中可以发送：

```text
/语音 今晚早点休息呀。
/tts 今晚早点休息呀。
/试听
/声音
你今天过得怎么样？用语音告诉我。
```

自然语音请求保留在正常聊天中，由原有 Replyer 使用原人设、上下文和当前问题生成回答，再将这一轮正文转成语音。“你今天过得怎么样？用语音告诉我。”会回答当前问题，不再读固定问候。否定、引用、假设句、声音讨论和设置咨询继续普通文字聊天。

`/语音` 与 `/tts` 直接朗读指定内容。`/试听` 才朗读固定 `voice.greeting_text`。命令成功后拦截本轮额外回复；自然问题仍走正常回复流程，只转换关联的那一轮，后续普通消息仍默认文字。

插件在 `maisaka.replyer.before_request` 用可信会话和目标 ID，通过 `message.get_by_id(include_binary_data=False)` 查询当前用户消息并追加本轮口语要求。`maisaka.reply.before_post_process` 只对这条请求保留完整正文，关闭文字删改、拆句及错字；图片和表情仍由宿主正常处理。`send_service.before_send` 要求两侧目标 ID 一致、唯一正文与准备的回答一致，再用实际回答合成替换 Voice 组件。所有 QQ 文字、语音和表情都会直接发送，不显示引用；动态语音成功时只发送语音本身，图片和表情不会与语音混发。内部目标 ID 仍保留给动态语音关联。组件保存正文，保持聊天历史可读。`send_service.after_send` 仅记录最终回执，不补发。

不新增发送 Tool 或额外模型调用，不订阅包含完整图片历史的 Planner/接收 Hook，避免超过宿主 16 MiB 单帧上限。所有 Hook 修改复制全部原参数；保留附件顺序、路由、存储、引用和打字设置。

私聊查询通过 SDK 2.8.1 返回会话字典本体，宿主的 `{success, stream}` 包装已经由 SDK 解包。加载时只读查询授权用户的既有会话，在 SDK 授予的运行目录保存 `voice-readiness.json`，只包含核验数量、时间及错误类型；不保存账号或会话 ID，不发送消息。

## 行为边界

- 只接受当前 QQ 私聊、当前授权请求者；发送前会查询宿主中的私聊流并核对流 ID、平台、用户和私聊属性。群聊、空授权列表和非 QQ 请求都会拒绝。
- 单次超时、合成异常、发送状态不明都不会自动重试。
- 自然请求只消费一次；合成失败、空音频或回答超过配置长度时，保留完整文字，不用固定音频代替。短期状态最多 64 项、180 秒过期。
- 显式朗读命令对同一聊天流和相同文本做 15 秒去重，处理中也拒绝重复请求。合成超时默认 20 秒，支持配置 1～60 秒。
- 所有 QQ 出站消息均不显示引用；内部关联 ID、路由、存储和打字参数保持不变。动态语音成功时不混发附件。
- 日志不写 QQ 号或朗读文本。
